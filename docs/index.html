保有銘柄の値動き比較

期間の始点を 0% として、各銘柄が何%動いたかを重ねて表示します。

    期間中の成績 （列名クリックで並べ替え・行にカーソルで線を強調）
    • 騰落率: 期間の始点から最新日までの変化率。
    • 高値から: 期間中の最高値から今どれだけ下にいるか。0% なら期間中の最高値圏。
    • 最大下落: 期間中に高値から一番大きく下げた幅（最大ドローダウン）。
    • 変動率(年率): 日次の値動きの大きさ（ボラティリティ）。大きいほど振れ幅が大きい。
    • 投資信託は基準価額（分配金再投資ベース）、株式は調整後終値。積立による買い増しの影響は含まないので「値動き」そのものの比較になります。
    • 投信の基準価額は営業日の夜、米国株は日本時間の朝に反映されます。自動更新は1日2回。
